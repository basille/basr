# Package index

## Basic, but Hopefully Useful, Functions

### Data management

Functions to handle data from vectors and data frames.

- [`colNAs()`](http://basille.github.io/basr/reference/colNAs.md) :
  Number of NAs by column
- [`extrange()`](http://basille.github.io/basr/reference/extrange.md) :
  Extended range
- [`kcut()`](http://basille.github.io/basr/reference/kcut.md) : Cut into
  classes of equal size
- [`multiple()`](http://basille.github.io/basr/reference/multiple.md) :
  Extract elements that appear multiple times
- [`nsubset()`](http://basille.github.io/basr/reference/nsubset.md) :
  Subset vectors, matrices and data frames based on value frequency
- [`reclass()`](http://basille.github.io/basr/reference/reclass.md) :
  Reclassify the values of a vector
- [`table()`](http://basille.github.io/basr/reference/table.md) :
  Modified table function to handle NAs

### Statistics

Functions for statistical utilities.

- [`confint()`](http://basille.github.io/basr/reference/confint.md)
  [`plot(`*`<confint>`*`)`](http://basille.github.io/basr/reference/confint.md)
  : Confidence Intervals for Model Parameters
- [`cv()`](http://basille.github.io/basr/reference/cv.md) : Coefficient
  of variation
- [`se()`](http://basille.github.io/basr/reference/se.md) : Standard
  errors
- [`round_sum()`](http://basille.github.io/basr/reference/round_sum.md)
  : Rounding that preserve sum
- [`summaryIC()`](http://basille.github.io/basr/reference/summaryIC.md)
  : Summary of AIC/BIC

### Graphs

Functions related to graphics.

- [`dynamitePlot()`](http://basille.github.io/basr/reference/dynamitePlot.md)
  : Dynamite Plots
- [`getcolors()`](http://basille.github.io/basr/reference/getcolors.md)
  : Choosing colors visually
- [`togrey()`](http://basille.github.io/basr/reference/togrey.md)
  [`togray()`](http://basille.github.io/basr/reference/togrey.md) :
  Convert continuous variable to grey levels

### Package management

Functions for package management.

- [`install_selected()`](http://basille.github.io/basr/reference/install_selected.md)
  : Install a list of selected packages by theme
- [`q()`](http://basille.github.io/basr/reference/q.md)
  [`quit()`](http://basille.github.io/basr/reference/q.md) : Terminate
  an R Session (with packages list saved)
- [`save.image()`](http://basille.github.io/basr/reference/save.image.md)
  : Save the current workspace (including attached packages)
- [`savepkglist()`](http://basille.github.io/basr/reference/savepkglist.md)
  [`attpkglist()`](http://basille.github.io/basr/reference/savepkglist.md)
  [`loadpkglist()`](http://basille.github.io/basr/reference/savepkglist.md)
  : Load or save the list of attached packages
- [`update_all_packages()`](http://basille.github.io/basr/reference/update_all_packages.md)
  : Update user packages (CRAN and GitHub)

### Utils

Utilitary functions.

- [`capwords()`](http://basille.github.io/basr/reference/capwords.md) :
  Capitalizing - every first letter of a word is changed to upper case
- [`date_locale()`](http://basille.github.io/basr/reference/date_locale.md)
  : Prints a date in any locale
- [`init_httpgd()`](http://basille.github.io/basr/reference/init_httpgd.md)
  : Init a web graphic device from httpgd
- [`memUse()`](http://basille.github.io/basr/reference/memUse.md)
  [`print(`*`<memUse>`*`)`](http://basille.github.io/basr/reference/memUse.md)
  : Memory usage of saved objects
- [`mv()`](http://basille.github.io/basr/reference/mv.md) : Rename an R
  object
- [`manual()`](http://basille.github.io/basr/reference/manual.md) :
  Generate package reference manual
- [`session_info_md()`](http://basille.github.io/basr/reference/session_info_md.md)
  : sessionInfo() formatted for Markdown
- [`writeFunction()`](http://basille.github.io/basr/reference/writeFunction.md)
  : Prints a function to a file
