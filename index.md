# basr

The package `basr` is a collection of basic functions that I wrote and
collected for my own convenience — hopefully they can be useful for a
wider audience.

## Installation

Install `basr` from CRAN:

``` r

install.packages("basr")
```

To install the package from GitHub (which may be ahead of CRAN from time
to time), use the package
[`remotes`](https://cran.r-project.org/package=remotes) or better
[`pak`](https://cran.r-project.org/package=pak) to install `basr`:

``` r

remotes::install_github("basille/basr")
pak::pkg_install("basille/basr")
```
